Lilt — personal macOS build
===========================

This archive contains a universal app for Apple Silicon and Intel Macs.
YouTube playback helpers are included inside Lilt.app; Homebrew is not
required for normal streaming.

1. Drag Lilt.app to Applications.
2. Open Lilt normally from Applications.

This build is signed with a Developer ID Application certificate, notarized
by Apple and includes a stapled notarization ticket. No Privacy & Security
override or quarantine removal should be necessary.
